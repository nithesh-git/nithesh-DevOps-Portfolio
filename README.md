Welcome to my DevOps Portfolio Website repository. This project represents my professional portfolio, designed to showcase my technical skills, cloud knowledge, DevOps tools expertise, certifications, and real-time projects. The website is fully responsive and built using HTML5, CSS3, and JavaScript, with version control managed through Git and GitHub. It is deployed using GitHub Pages for live access.

This portfolio highlights my experience working with DevOps and Cloud technologies such as Docker, Kubernetes, Jenkins, Terraform, Azure, Python, MySQL, and CI/CD pipelines. The goal of this project is to demonstrate my ability to design, build, and deploy scalable and automated solutions following DevOps best practices.

The repository includes the main website files such as index.html, style.css, script.js, images folder, and my resume for download. The deployment process is handled through GitHub Pages by pushing the code to the main branch and enabling the Pages feature in repository settings.

Through this portfolio, I aim to present myself as a dedicated and growth-oriented DevOps Engineer who is passionate about automation, cloud infrastructure, and continuous integration and delivery practices.
